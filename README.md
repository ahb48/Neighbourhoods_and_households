# Neighbourhoods_and_households
Contains all scripts and notebooks used to produce the results in 'Epidemiological dynamics in populations structured by neighbourhoods and households'.
Each .ipynb notebook produces the results for a particular figure while the .py files contain objects used in the analysis and are called in the notebooks. The data file 'sequences.csv' contains a table detailing the sequence of neighbourhood infections corresponding to each arbitrary sequence index in Figures 10 and 12 in the manuscript.
